# Blog Monetization Runbook - 2026-10-04

GitHub Pages remains the public publication/archive layer. Use a separate monetized publishing surface for commercial activity.

## Target stack
- WordPress.com Free - canonical publishing layer
- Payhip Free Forever - digital-product checkout
- Kit Free - email capture and broadcasts
- Google Search Console - search measurement

## Verification gates
- Never invent checkout URLs, affiliate IDs, form URLs, tracking IDs, or revenue.
- Never bypass account security prompts.
- Mock/internal events do not count as revenue.
- Only real cleared transactions count as revenue.
